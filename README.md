# Lysergia — Enhanced English Edition

A self-contained 2D browser adventure set in Mescaline, a city where cyberpunk streets, medieval ruins, and broken universes overlap.

## Run the game

1. Extract `Lysergia_Enhanced_English.zip`.
2. Open the extracted folder.
3. Double-click `index.html` to launch the game in Chrome, Edge, or Firefox.
4. Select **Start Adventure**, choose a warrior, and play.

The game uses no external libraries or separate image files. After downloading the ZIP, it can run offline.

## Warriors

- **Onírico** — a carefree cactus warrior. The normal attack fires green energy bolts; the special attack releases a thorn shockwave. His transformation boosts damage and resistance.
- **Hideyoshi** — a calm polar-bear samurai. The normal attack is a katana slash; the special attack sends a powerful water wave. His transformation boosts movement speed and attack damage.

Both characters can equip armor. Press `E` to toggle it and `Q` to activate the temporary transformation when it is ready.

## Levels

1. **Mesca City — Neon Streets:** rain-soaked streets, neon towers, flying traffic, and hostile creatures.
2. **The Rusted Kingdom — Medieval Frontier:** moonlit castles, ancient walls, suspended bridges, and increasingly dangerous enemies.
3. **The Rift — Multiverse Edge:** floating fragments of different realities gather around the multiverse rupture.

Defeat every enemy in a level to unlock the exit. Reach the exit to advance. The final scene keeps the question of dream versus reality deliberately ambiguous.

## Controls

| Key(s) | Action |
|---|---|
| `A` / `D` or `←` / `→` | Move left / right |
| `W`, `↑`, or `Space` | Jump |
| `S` or `↓` | Crouch |
| `J` | Normal attack |
| `K` | Special attack |
| `L` | Kick |
| `E` | Toggle armor |
| `Q` | Temporary transformation |
| `Esc` | Pause / resume menu |
| `R` | Restart the current level |

## Notes

- Resolution-aware canvas rendering and detailed procedural scenery are used to make the backgrounds sharper while keeping the game lightweight.
- The visuals are custom-drawn by the game code; this build does not use external sprite packs.
- This is a self-contained playable browser edition, not a packaged Windows executable.
